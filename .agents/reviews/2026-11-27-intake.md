## 1. Summary

**Health:** Mycelis (`v1.2.2`) is a mature, well-modularized Go + Next.js + Python-ops codebase (`1,419` scanned files with `0` legacy 300-line cap exceptions, `0` TODOs in `interface/` and `ops/`, `4` TODO/Hack markers in `core/`, `28/28` Go test packages passing, `391/391` pytest tests passing, `tsc --noEmit` clean, and `83/83` in-app doc manifest paths verified on disk). However, **new feature delivery should NOT start before a short hardening/reconciliation pass** because the repository's own baseline gate currently fails (`logging.check-topics` exits `1` on **56 hardcoded `swarm.*` literals** across 6 Go server files), CI workflows are disabled (`if: false`), and several security/reliability defects sit on `main`/`dev`.

**Top 3 Risks:**
1. **Broken baseline gate + zero CI enforcement:** `logging.check-topics` fails on `v1.2.2`, all 4 `.github/workflows/*.yaml` files have `if: false` on every job, and no local git hooks exist—allowing regressions onto `dev` and `main`.
2. **Auth, RBAC & Helm secret hygiene gaps:** `RequireMinimumRole` is missing on most mutating `/api/v1/*` handlers (including `POST /api/v1/memory/promote`, `POST /api/v1/memory/resolve-conflict`, and `POST /api/v1/runs/{id}/interject`), allowing a `viewer` key to mutate state; `charts/mycelis-core/templates/searxng-deployment.yaml` commits a plaintext secret (`mycelis-k8s-searxng-search-secret`) and unpinned `:latest` tag; `.env` still carries the sample primary API key placeholder (`mycelis-...prod`) with no break-glass key.
3. **Silent failure & request-context bugs + severe governance-doc drift:** `memory_arbitration.go` returns HTTP `200 {"ok": true}` even when DB persistence fails; `DurableFilesOperatorView.tsx` reports success even if `/refine` fails; `HandleRunInterject` passes `r.Context()` into a background goroutine; and `CLAUDE.md`, `README.md`, and `.state/V8_DEV_STATE.md` contradict `AGENTS.md` on Windows-only vs. WSL execution and carry stale `v0.8.3`/`v0.8.4` `ACTIVE`/`IN_REVIEW` markers.

**Delivery readiness:** **Blocked on Slice 1 (Baseline Gate & Correctness Hardening)** before resuming new feature waves.

## 5. Risk Map

1. **Security Boundaries (High):**
   - **Sparse RBAC (`core/internal/server/`):** Mutating routes (`POST /api/v1/memory/promote`, `POST /api/v1/memory/resolve-conflict`, `POST /api/v1/runs/{id}/interject`, etc.) do not call `RequireMinimumRole`, allowing `viewer` tokens to mutate state.
   - **Committed Helm secret & unhardened pods:** `charts/mycelis-core/templates/searxng-deployment.yaml:14,51` hardcodes a plaintext secret and uses unpinned `searxng/searxng:latest` without `securityContext`/`resources`/probes. `interface-deployment.yaml:19-42` also lacks `securityContext`, `resources`, probes, and `serviceAccountName`. `network-policy.yaml:20-24,63-73` allows unrestricted ingress on `8080` and wide `0.0.0.0/0` egress on 9 ports, and omits `interface`/`searxng`.
   - **OIDC & query tokens:** `auth_oidc.go:91` only supports symmetric `HS256` (no RS256/JWKS); `auth.go:187-189` accepts `?token=` in query strings.
   - **Local `.env` posture:** `auth.posture` shows the sample `mycelis-...prod` primary key and missing break-glass key on this dev host.
2. **CI / Regression Gate (High):**
   - All 4 `.github/workflows/*.yaml` files are disabled (`if: false` on every job), and there are no local git hooks or secret scanners.
   - `logging.check-topics` is currently red on `dev`/`main` (`v1.2.2`), blocking `ci.baseline`.
3. **Reliability & Concurrency (Medium-High):**
   - `conversations.go:237-249` (`HandleRunInterject`) uses `r.Context()` inside a background goroutine (dropped writes on request completion).
   - `memory_arbitration.go:104-108,165-169` swallows DB errors and returns HTTP `200 {"ok": true}`.
   - `DurableFilesOperatorView.tsx:189-200` swallows fetch/HTTP errors on `/refine` and reports success.
   - Unchecked `nc.Subscribe` calls in `bootstrap/service.go:106,111`, `swarm/agent_lifecycle.go:72,76`, `swarm/team_runtime.go:53`.
4. **Data & Migrations (Medium):**
   - Only `14` of `39` `.up.sql` migrations have `.down.sql` rollbacks; `027` is absent; `013`/`015` hardcode `localhost`/`127.0.0.1:11434`.
5. **Untested Paths & Technical Debt (Low-Medium):**
   - `7/37` Go packages have no test files (`deploymentcontext`, `signal`, 4 `cmd/*` tools, generated `pkg/pb/swarm`).
   - Only `4` TODO/Hack markers in `core/` (`router.go:187`, `archivist.go:97`, `triggers/engine.go:163`, `soma_test.go:19`), `0` in `interface/`, `0` in `ops/`.
   - `0` size-cap pressure (`1,419/1,419` files `<= 300` lines; `ops/quality_legacy_caps.txt` empty).
